# 无素材组合套增强版

无素材指不需要外部图片、录屏或视频。画面仍然需要具体内容：问题、判断、步骤、数字和这些信息之间的关系。先确定这一段要解释什么，再填参数；组件负责把它们组织成画面。

增强版通过正常 `POST /api/jobs/{job_id}/component-demo` 入口提交，指定 `composition: "rich"`，由 Worker 执行 `component_demo → director_demo → end`。同一套样片的修改继续使用原任务的新 revision。样片生成后等待品鉴；不等同于原视频导演审核通过。

## 六套分工

| 套件 | 什么时候用 | 信息搭配 | 数字的作用 |
| --- | --- | --- | --- |
| B01 问题开场 | 先提出和观众有关的问题 | 问题输入、疑问句、计数器、核对线索、强调句 | 告诉观众需要留意几项，不编风险概率 |
| B02 概念解释 | 纠正一个混淆，拆开几个判断 | 旧说法改写、白话解释、词语翻换、计数器、关键句 | 说明概念拆成几项，不把条目数写成调查结果 |
| B03 两种情况对比 | 对比两种做法或两个对象 | 文字对照、同口径数字图、换词、对比结论 | 给出可比较的动作数、花费等；多一步不等于保证安全 |
| B04 数字账本 | 解释金额、次数和合计 | 大数字、逐笔数据图、算式分解、说明、收束句 | 每笔与合计相互核对，避免数字只有视觉冲击而没有口径 |
| B05 步骤演示 | 没有录屏时，讲清要做的动作 | 编号流程、步骤说明、计数器、提示句、收束句 | 编号和总步数对应，说明跟随当前步骤 |
| B06 结论行动 | 从一个情景落到能执行的动作 | 明示模拟的聊天、行动原则、计数器、行动清单、强调句 | 让观众记住几项动作，不冒充真实聊天或统计 |

## 内容输入

每套都需要 `content.title`、`content.body`、`content.takeaway`。增强版标题和收束句最多 18 字，正文最多 60 字；短句优先，避免为了填满空间塞长段落。

| 套件 | 其他必填内容 |
| --- | --- |
| B01、B02 | `items` 三项；`metric` 数字锚点 |
| B03 | `items` 两项文字对比；`numeric_items` 两项同单位数字 |
| B04 | `metric` 合计；`numeric_items` 三笔同单位数字 |
| B05 | `items` 三步；`supporting_items` 三条对应说明；`metric` 步数 |
| B06 | `items` 两到三项行动；`supporting_items` 两条模拟对话；`metric` 动作数量 |

`metric` 包含 `label`、`value` 和可选 `detail`。`value` 是 0–99999 的 ASCII 整数加 1–2 个汉字单位，例如 `399元`、`3步`。B01、B02、B05、B06 用数字显示条目数，数值必须等于 `items` 数量。`numeric_items` 格式为 `标签:数字加单位`，标签最多 12 字，例如 `第1次:133元`；必须使用同一单位。B04 合计必须等于三笔输入之和。这里的样片使用明示的演示数字，后续真实选题应由当前任务的事实和来源提供数字。

增强版时长为 12–20 秒。时长由内容决定，不固定每两三秒切一次。内部按问题、解释、数字关系、收束逐步展开；已经显示的信息可保留作参照，避免反复重播同一张卡片。

## 视觉检查

- 白字直接放在深色背景上，标题不加白色底板。
- 主体、数字、补充说明和收束句各有位置；图表标签不能被控件或强调层压住。
- 数字旁边保留单位和含义；演示数字、机制示意明确标注。
- 步骤说明与当前点亮的步骤对应；账本图注明累计或逐笔口径。
- 组件用量按实际原生调用登记，背景、连接线、边框不冒充组件 ID。
- 交付检查实际 MP4 的早、中、晚帧，并完整解码；不能只看 JSX 或封面判断成功。

旧 `composition: "basic"` 样片保持可读。增强版仍然只接收结构化内容，不允许传任意时间轴、JSX、CSS 或未知组件参数。
