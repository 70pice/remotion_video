## 指标如何影响写作与审查

| 关注维度 | 写稿时能做什么 | 审查时检查什么 |
| --- | --- | --- |
| 开头留存 | 尽早出现具体处境、问题与观看理由 | 首句是否空泛、铺垫是否挤掉价值、承诺是否兑现 |
| 持续观看与整体完播 | 每段交付新信息，逐步回答小问题 | 空问、重复、拖延答案、无依据反转和结尾未回答 |
| 信息密度 | 删除同义重复，用案例解释复杂内容 | 是否把参数、术语或加速口播误当有效信息 |
| 点赞 | 提供有证据的新认识与具体共鸣 | 是否夸大、虚构经历或煽动焦虑 |
| 收藏 | 留下适用场景、选择条件与边界 | 判断是否可用，而不是机械塞清单 |
| 转发 | 明确受众，提供可转述的核心解释 | 是否夸大为人人适用或强求转发 |
| 评论 | 回答后可选一个真实、具体的讨论点 | 是否假争议、空泛求互动或用 CTA 替代答案 |

“前 3 秒 / 前 5 秒”是开头设计关注点。文案节点没有实测音频，不能用
字数或预计 1.3 倍语速宣称覆盖了某个时间窗口；实际内容落在哪几秒，需要
配音和时间对齐后核对。这里没有新增音频时间窗自动验收功能。

## 指标如何影响导演与剪辑

| 关注维度 | 导演如何生成画面 | 剪辑如何检查 |
| --- | --- | --- |
| 开头留存 | 按实测 3/5 秒窗口匹配具体场景、证据或问题关系 | 检查覆盖窗口的全部镜头与字幕，定位观看理由是否交付 |
| 持续观看 | 随内容从案例到证据、对比、解释和结论，保持对象与颜色含义连续 | 找出重复大字、无关装饰、解释断层，不机械要求快切 |
| 信息密度 | 一屏一个主重点，减少重复文字与卡片，保留必要条件 | 按实际停留时间、字幕重合与内容量判断阅读负担 |
| 点赞与评论 | 呈现脚本已有认识与具体讨论点，不夸大证据、不添加假争议 | 检查画面是否偷换结论，互动是否替代答案 |
| 收藏与转发 | 让脚本已有的场景、选择依据与边界在画面中清楚呈现 | 将旁白缺口交回编剧，将画面遗漏或歪曲交回导演 |

检查窗口使用 `[0,min(duration_in_frames,3*fps))` 和
`[0,min(duration_in_frames,5*fps))`，与当前镜头帧区间取交集，并对照
字幕的实际毫秒时间；不能只检查第一镜，也不能用预估语速换算。
这些方法写进 Prompt，由模型根据输入做结构判断，不是新增的程序检查器，
也不能从时间轴直接判定像素、动效的实际展示或观众行为。

导演在现有镜头内优化组件、资产与屏幕文字，输出新的完整分镜；继续保留
音频、字幕和镜头数量、顺序、帧区间。剪辑模型输出预检意见，当前不会
自动把建议写回分镜；阻断项按已有流程等待处理，非阻断意见保存供 Review。
这次没有新增自动修订循环、细分镜头、录屏播放或自由动效参数。

最终复核检查承诺、证据、屏幕表达与结论的一致性，不宣称已经完整看片或
测得留存提升。实际成片是否好看、动效与阅读时间是否合适，仍需真实预览。

## 与真实表现数据的边界

文案节点只能检查结构、事实和表达。真实留存、观看、点赞、评论、收藏和
转发数据需要发布后从实际平台记录中读取。当前没有新增账号后台连接、
数据拉取、阈值配置、指标评分或发布后复盘节点。

没有后台数据仍然正常创作与审查；不得编造播放量、完播预测、留存提升
百分比或“必爆”保证。日后输入真实历史表现时，需要按平台定义、统计周期、
视频时长及样本条件解释，不能把不同口径的指标直接比较，也不能从单条
视频归纳出普遍因果。合格阈值应来自用户明确的目标与可比较的历史数据。

Notion 记录是创作方法资料，不是本期产品或事件的事实依据，不加入文案
`source_refs`。本次将规则保存为本地 Prompt 快照，运行时不额外访问 Notion。
后续 Notion 修改不会自动同步。

- [director.md](../videoagents/prompts/director.md)：将开头窗口、视觉解释、
  持续信息交付与收藏转述价值落实到现有分镜生成。
- [editing.md](../videoagents/prompts/editing.md)：根据实测时间检查画面交付
  与阅读负担，将问题定位到镜头并交给负责角色，不宣称已自动修改。
- [review.md](../videoagents/prompts/review.md)：复核承诺、证据与画面的一致性，
  避免为了互动扩大结论或隐藏条件。

Prompt 加载器有缓存，节点常量在模块导入时组成；长期运行的 API 和 worker
需重启后读取新内容。已经保存的稿件和分镜不会因修改 Prompt 自动重做。
加载与节点契约测试可以验证各角色读取新规则及已有契约未破坏，
不能验证真实留存、完播或互动效果；仍需后续实际稿件 Review 与发布数据。
