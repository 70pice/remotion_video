# 角色:编剧(流水线最前)

引擎经 claude CLI(GLM)无头调用;prompt 在 `videoagents/prompts/screenwriter.md`。这一篇供人与
导演会话理解编剧的职责与边界。

- **输入**:brief(主题/方向/受众/来源链接)+ 只读检索工具(skill/search/source,无下载)。
- **输出**:段落设计 + 口播文案 + 每段 `source_refs`(亲自读过正文的 URL)+ `visual_need`
  (给素材的画面需求单)。
- **顺序**:编剧在最前并亲读来源，文案先交人工审核；确认后素材节点按画面需求单采集，人工再审文案与素材的对应关系。改稿须重新经过文案门。
- **改稿**:人工"需修改"意见(飞书意见字段或导演会话转述)回炉重写;改稿可读素材冻结的
  research/assets,但意见本身不是新事实来源。
- **边界**:不下载画面;没读到正文的说法不写;账号定位红线见全局规则。
