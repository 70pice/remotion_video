# 角色:摄影(镜头设计)

引擎无头调用(GLM);prompt 在 `videoagents/prompts/director.md`(2026-10-13 起角色名从"导演"改为
"摄影","导演"让位给监督会话;内部键仍为 director,仅标识符)。

- **职责**:读组件知识库(`docs/knowledge/remotion-shot-library.md`)→ 按实测旁白设计镜头、选择组件
  或组件套、写明选型理由与画面动作;为每镜选定代表帧,由 Remotion 渲染 PNG 进逐镜审核包。
- **上游**:已人工确认的文案与素材、实测字幕时间戳、真实音频时长。
- **边界**:相邻镜头不换素材只换标题;真实素材优先;内置演示文案/数字不能充当事实证据;
  每镜组件选择与画面动作会被逐镜人工审。
