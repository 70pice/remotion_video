# 项目知识库

- [Remotion 组件知识库](remotion-shot-library.md)：导演生成镜头前的当前组件知识库，逐项列出 196 个生产组件的画面效果、适用场景、横竖版路径和使用边界；历史飞书原表保留为 [结构化快照](remotion-shot-library.feishu.json)。
- 组件的当前实现以 [生产清单](../../videoagents/component-manifest.json)、[路径索引](../component-paths.json)、[使用指南](../component-use-guide.json)、[组件库说明](../component-library.md) 和实际横竖版源码为准。

导演先读组件知识库，再规划镜头。当前导演 Prompt 已注入按任务用途过滤后的完整组件目录；如果运行环境没有文件工具，就以注入目录作为知识库摘要，不把文件链接当作已读取内容。原表中的历史验证或预览地址属于来源记录；更新知识库时重新读取并核对目录与当前源码。
