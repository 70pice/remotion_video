# 普通人与 AI：账号镜头组合规则

2026-10-10 用户确认。用于素材准备与导演选镜头；具体事实、已确认文案、实测音频和现有组件契约优先。

## 选择顺序

主题 → 段落要回答的问题 → 素材能支持的内容 → 场景组合 → 具体组件。

账号画面围绕人遇到了什么、AI 实际做了什么、结果与代价、对观众有什么意义组织。
这些是检查问题，不是每期必须照搬的章节。按 brief 的本期方向和受众取舍；一个选题可包含多种段落任务。
主题缩小组合候选范围，素材条件决定候选能否成立。完整组件库继续学习与使用，不设固定的小组件白名单。

## 主题与素材准备

| 主题 | 优先准备的真实素材 | 组合方向 | 必须保留的边界 |
| --- | --- | --- | --- |
| 工作与收入，包括成功与失败案例 | 人物或工作现场、实际操作、作品或交付结果、收支或效率证据 | 处境 → AI 操作 → 产出 → 结果与成本 | 自述与核实分开，营收与利润分开；没有收支证据不能宣称赚到钱，个案不证明可复制 |
| 诈骗与避坑 | 原始说法或消息、事件资料、官方通报、核验结果 | 发生了什么 → 让人相信的线索 → AI 的实际作用 → 如何判断 | AI 是否参与及作用须有依据；不伪造聊天或收集可复刻作案步骤 |
| 家庭与生活，包括教育、健康与陪伴 | 对应生活场景、真实操作、使用结果、失败与限制材料 | 原来的麻烦 → 使用过程 → 变化 → 仍有的问题 | 官方演示、自述与独立验证分开；不把辅助场景画面当效果证明 |
| 热点说法核实 | 原始说法、原文出处、同口径数据或测试、相关反例 | 看见说法 → 查看证据 → 比较差异 → 回答问题 | 搜索摘要不是原文；不同任务、版本、日期或单位不能直接拼成胜负 |

人物画面不可得时，可以用真实工作对象、任务输入或事件资料建立处境，不虚构人物。
有相关、已导入且可用区间足够的真实视频时优先使用。只有图片也可以；没有相关素材就记录具体缺口。

## 素材条件与镜头职责

| 段落任务 | 素材条件 | 优先镜头 | 组合条件 |
| --- | --- | --- | --- |
| 看见人、现场与处境 | 对应人物、事件或任务的实拍、照片或真实对象 | video / image_focus | 同一个对象持续解释时保持连续；切镜交付新信息并换成相关新素材 |
| 看懂 AI 做了什么 | 真实输入、录屏、操作和结果；视频区间已经核对 | video / 合适的设备或界面容器 | 手机界面才考虑手机框，桌面界面才考虑桌面框；保持关键文字可读 |
| 核对一个事实 | 真实出处、原文与对应区域 | evidence / 可承载原文的社区组件 | 同一张原文从出处讲到关键句时连续保持，不拆成反复入场的两镜 |
| 看清差别 | 可比较的两份结果或有依据的两种说法 | comparison / 合适的对比组件 | 锁定共同任务与比较条件；观点对照须标清说话者，不冒充实测结果 |
| 理解数字 | 原始数字、来源、单位、日期及口径 | data / 合适的数据组件 | 单一数值不支持趋势或排名；社区预设的演示数字不支持本期结论 |
| 理解过程 | 有来源的先后动作或阶段 | steps / 合适的流程组件 | 并列特点不当作步骤；按实测 captions 安排支持的揭示时刻 |
| 理解判断与收束 | 已确认文案中的判断或结论，及其依据 | keyword / conclusion 或继续保持结果画面 | 不新增推荐、金句或行动建议，不把判断包装成已核实事实 |

以上是镜头职责与选择条件，不限定只能使用这些适配器。社区组件须从本任务可选清单中选择，
实际槽位、阅读负担和内容语义同样满足条件时才使用。代码、终端和 Agent 日志只服务确实涉及开发或技术操作的段落。

## 素材节点如何交接

沿用 MaterialResearch 的现有字段。将以下内容简短写入 visual.description 和来源文件的素材备注，
description 总长仍不超过 1000 字；不增加主题、镜头、坐标或计划输出字段：

- 叙事用途：人与处境、AI 动作、结果证据、对比、数字、过程或边界，按实际内容选择。
- 支持内容：能支持哪条说法、涉及哪个对象；辅助理解画面须明确不能作为事实或效果证明。
- 可用画面：可读区域、实测视频区间、已核对的证据焦点。
- 使用边界：不能证明什么，数字和对比的单位、日期、版本、样本及条件。

先覆盖本期问题所需的内容差异，再补可替换画面；不为集齐主题表、组件或固定镜头数采集无关素材。
缺少某个事实写 [证据缺口]，缺少对应画面写 [画面缺口]，同时写清可以补什么。

## 导演如何组合

1. 在内部规划中明确段落问题、叙事任务、对应 asset_id/source_refs、素材边界和可用区间。
   这些是选镜头依据，最终仍只输出现有 shots，不新增字段，也不把内部标签写成屏幕正文。
2. 按主题选组合方向，再按素材条件选通用场景 Playbook 和具体组件；同一段可以混合不同职责。
3. 切镜的理由是新信息、对象或证据。复杂图片可连续停留；保持同一叙事主体不等于相邻镜头复用同一素材。
4. 继承导演现有的深色母版、字体、字幕安全区、来源标注和颜色语义；只使用组件已开放的字段。
5. 素材不足时使用有限的解释镜头并保留缺口，不重复图片、循环视频或编造素材填满组合。

例如工作收入段落在素材齐备时可采用：真实工作场景 → 实际 AI 操作 → 交付结果 → 收入与成本证据 → 本期判断。
这是组合示意，不是具体任务分镜，不包含虚构人物、数字、音频或镜头时间。

## 执行与验证边界

素材和导演的角色 Prompt 分别包含与自身职责对应的规则，继续由正常任务 API、Worker 和生产图执行。
本规则属于创作指导；已有素材、时间轴、组件参数及任务归属程序校验继续执行，不能据此宣称已验证成片质量。
Prompt 在进程内缓存，已运行的 Worker 需在无活动任务时重新启动才能读取修改；冻结研究包和完成任务不会自动重采或重做。
真实效果须在明确的视频任务中查看实际产物。本次规则确认不自动创建任务、调用配音或发布视频。
