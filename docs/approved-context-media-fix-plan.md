# 已审同类示意素材校验修复计划

1. 复用现有只读摄影恢复验证，取得精确联合批准投影；可信媒体限于投影素材、当前素材与冻结 research 来源关联的交集。
2. 时间线校验新增可选批准来源集合。未关联素材只可作为明确标注同类、示意/示例、非涉案及真实域名的 context_example；原证据关联、默认规则与组件限制保持。
3. 摄影、代表帧、剪辑与导入草稿入口统一取得批准集合；不改模型输入、schema、提示词、产线状态或既有产物。
4. 回归覆盖真实批准/恢复批准、未批准、过期批准、文件变更、缺失标签、跨任务、冒充证据及原规则；运行定向 pytest、ruff 与适用静态检查后提交。

批准集合只作为校验函数的 keyword 传入，不写入模型上下文、素材元数据或批准记录。文案未关联画面必须保留 `context_example`、`另案示例`、真实来源域名、`同类`、`示意/示例` 与 `非涉案/非报告涉案` 标注；既有语义证据关联和覆盖容量计算不变。原联合批准或摄影恢复批准任一核验失败时仍阻断。

复审补充：普通生产入口统一执行原有逐段证据关系校验，不能把同类示意改标为 `source_evidence`。新增批准路径要求独立且精确的来源域名 token，域名子串不构成匹配。普通 `draft`/分镜导入会增加 revision，仅证明旧版输入在导入时有效，不继承旧版批准；新版本必须重新经过原文案批准与文案/素材联合人工门，直接摄影或剪辑仍拒绝旧 proof。
