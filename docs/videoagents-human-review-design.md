# 制作阶段人工审核

2026-10-05：用户要求文案、导演分镜、剪辑成片均在进入下一阶段前暂停，由用户检查方向、吸引力、画面与节奏。阶段确认不能替代最终发布审核。

## 改造与验证计划

1. 复用 HumanReviewNode，把文案审核接在机器文案讨论和 ScriptGate 后、配音前；分镜审核接在 TimelineGate 后、渲染前；剪辑审核接在实际视频生成后、成片机器审核前。失败仍走已有补充待办。
2. 阶段审核显示当前产物及具体检查事项。确认继续，提交反馈要求对应角色返工并再次审核，取消停止。原内容、版本、审核 token 和文件 hash 继续绑定；返工使依赖旧产物的审核失效，不能沿用旧模型审查决定。
3. 文案改为证据推动的自然讲述：问题、案例、解释、转折，最后回答开头。移除强制朗读“观点：/个人感受：”的提示词要求；结尾不另起个人观点或说教段，事实与基于证据的推断仍保留来源。
4. 对照已有“基地”参考片记录，并尝试读取作者同题作品的实际字幕；取得什么、未取得什么如实记录，不用片名或画面猜测结尾原话。
5. 用模拟角色和真实 LangGraph interrupt/resume 回归验证：未确认无下游调用；确认只放行当前阶段；返工反馈到角色并重新暂停；陈旧回复/文件变更拒绝；阶段审核不授予发布资格；历史最终人审仍能恢复。再完成 API、React、类型检查、构建与契约验证。

本次不发起真实付费制作，不替用户通过任何生产待办。新建流程使用新的阶段审核；历史成片不会被伪装为已经经过新增审核。
