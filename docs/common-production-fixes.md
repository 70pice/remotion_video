# 共性生产修复与恢复入口

这些能力适用于所有视频任务。默认生产模型、推理档位、语速和超时保持原配置，
任务隔离、未决提交屏障与人工审核仍然生效。

## 修复范围

- CLI：保留脱敏的 API、协议、进程和校验错误类型；研究事件流与业务结果分别限流；
  结构化输出最多首次加两次纠正，限制 CLI 内部重试；临时文件清理失败不覆盖原结果。
- 兼容：Windows 媒体可执行文件与 CLI shim 使用独立参数启动；中文来源按 BOM、HTTP、HTML
  编码声明解码，正文有界保留。见 [来源规则](videoagents-source-decoding.md)。
- 审核：文案确认后才能采集素材；部分素材取舍不代表整包批准。飞书按 ID 增量更新，
  保留人工字段、评论和附件，新镜头附件使用创建回执 ID；缺帧或上传失败明确报错。
- 恢复：仅素材重采、补采与仅摄影恢复通过显式入口保存新版本，核验已有批准及文件指纹。
  只有能证明原输入的 COMPLETED 摄影候选可以参与后续修复。见
  [恢复边界](videoagents-unknown-restart.md)和[素材选择](videoagents-material-selection.md)。
- 画面：文字按真实槽位测量；数据与单位保持单行；去除重复关键词及分层列表/指标。
  达到可读字号仍放不下时明确失败并回摄影，不隐藏裁切或无限缩小文字。
- 轮播：单个 `Snapcn-PhoneFrame` 支持 2～8 张已导入图片，外框与标题持续显示。
  每页独立校验来源和时间范围，全部图片进入渲染打包；见[组件知识库](knowledge/remotion-shot-library.md)。

## 代表帧刷新

```sh
videoagents refresh-shots <job_id> --idempotency-key <unique-key>
```

在当前逐镜待审门重渲同一方案的全部代表帧。命令持久化并幂等；失败后继续原方案，
不重新规划，不继承旧审核。完成后仍需整包人工确认。

## 成片后局部视觉返工

```sh
videoagents revise-visuals <job_id> --shot-ids <shot-a,shot-b> --note-file <feedback.md> --idempotency-key <unique-key>
```

保存新 revision，冻结文案、素材、真实音频、字幕及未选镜头。正常流程处理所选镜头，
生成代表帧并重新停在完整逐镜审核。可加 `--preview` 渲染所选范围的动态预览（最多30秒）。
刷新和局部返工不自动授予成片发布状态。

## 验证边界

回归使用合成输入、模拟 CLI 和浏览器实际文字测量，不以具体视频内容作为通用默认值。
组件排字修复只覆盖已测组件，不代表整个组件库已经完成像素审计。
外部模型、飞书或网络仍可能失败；诊断与恢复能力不保证未知提交未产生用量。
