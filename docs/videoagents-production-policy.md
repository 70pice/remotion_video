# 生产制作约定与验证

2026-10-05 用户确认：项目负责制作，操作者负责监工和兜底。

生产路径为任务 API → 持久化命令 → Worker → LangGraph。素材节点在第一位；文案与文案审查交替讨论，人工确认文案后进入配音；配音提供真实音频及时间轴；导演先学习竖版组件，再生成分镜；剪辑按分镜执行 Remotion，生成视频后结束。

2026-10-07 用户更新：只保留文案人工审核，删除独立时间轴检查节点、分镜人审、剪辑成片人审、成片机器审核和最终发布人审链。时间轴及素材的程序校验仍在导演、剪辑节点执行；`await_input` 只在新生产流程中承担补充输入和失败恢复。成片以 `DRAFT` / `complete` 结束，不创建审核通过记录或自动标记发布就绪。文案返工仍交给编剧修订，再检查并重新人工审核。口播不要求朗读“观点：/个人感受：”，结尾以证据和场景自然回答开头。详细编排见 [阶段人工审核](videoagents-human-review.md) 和 [生产图精简](videoagents-graph-simplification.md)。

本次改造计划与验收：

- API 与 React 新建/修改需求入口固定 1080×1920、30 fps，旧任务可读取。
- 素材允许真实 MP4，与图片一样保留来源、哈希、文件和用途信息；探测真实视频流、尺寸及时间，拒绝音频伪装成视频。
- 导演学习全部竖版组件的源码与使用说明，保存清单覆盖和源码指纹。组件选型仍按用途授权过滤。
- 视频镜头使用 `video` 组件，支持显式起止秒数、contain/cover 和已核验归一化裁剪；不能循环凑时长。视频片段须覆盖镜头时长。
- 配音默认保持原始语速并使用 expressive 讲述风格；剪辑使用实测音频时间轴。字幕和来源保留，主要画面应适合手机观看。
- 字节供应商返回的每词时间与置信度保留原值。低于 0.8 记录同步风险，不再丢弃全段；0.8 是项目提醒线，官方没有规定该合格线。正文/段落覆盖、区间不重叠、音频 hash 及实测时长仍严格经过 AudioGate。`verified` 指这些机器检查，不能代表独立音频识别或人工听审。[官方时间戳定义与 TTS2.0 样例](https://docs.volcengine.com/docs/6561/1329505?lang=zh)
- 验证覆盖入口约束、视频导入与片段边界、组件学习先后顺序及完整性、前端视频编辑、渲染实际解码。真实制作通过项目入口提交，制作完成与外部平台发布分开处理。

历史独立 demo 不再作为生产入口。遇到暂停，通过正式人工补充入口或修复通用实现后续跑，禁止直接填最终分镜、伪造时间轴/审核结论或注册外部成片冒充全流程完成。

导演模型只返回 `{"shots": [...]}`，程序把经校验的镜头合入实测 Timeline。
镜头数量、顺序、ID 与起止帧仍逐项核验；画幅、音频路径与全部字幕由代码保留。
导演仍读取完整字幕判断前三秒与画面时机，音频素材元信息中的重复 alignment 不再发送。
CLI 超时后的 UNKNOWN 记录仍保留，修复不会自动重投同版本的未知请求；通过草稿 API
保存新版本后重新执行，并按内容与设置指纹复用仍匹配的真实音频。

全部角色的 CLI 子进程都剥离桌面父会话的 session、thread、pipe 和权限档案
环境变量。普通登录与代理环境保留；仅素材研究模式补充本地工具 PATH 与 UTF-8。
这保证角色会话独立，不改变最终完成回执、UNKNOWN 屏障或调用预算。
