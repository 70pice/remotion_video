# Bundled font assets

- Packages: `@fontsource/inter@5.3.0` and `@fontsource/source-serif-4@5.3.0`.
- Original repository: https://github.com/fontsource/font-files
- Font authors: Inter Project Authors; Source Serif 4 Project Authors. See each unchanged LICENSE file for exact copyright and terms.
- Font licenses: SIL Open Font License 1.1, separate from Snapcn's MIT component license.
- Download method: `npm pack --ignore-scripts` into Windows TEMP, without adding an npm dependency or running package scripts.
- Both package archives were checked against npm's published SHA-512 integrity. Per-asset SHA-256 and source names are in source-files.json.
- Selected files are unchanged Latin WOFF2 assets. They provide no Chinese glyphs.
- Inter: normal weights 400, 500, 600 and 700. Source Serif 4: normal weights 400 and 600.
- Loader reference: https://www.remotion.dev/docs/fonts#local-fonts-manually
