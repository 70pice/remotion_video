# 文案 Agent：讨论改稿交付指令

这是与文案审查的讨论改稿。当前稿件是
`script_discussion.rounds[-1].script`，对应审查是该轮 critique；前面各轮
只是已经完成的稿件、回应和审查，不是工具历史。

先核对最后一轮仍未解决的问题，再修改相关段落及必要的衔接；保持已经有效
的主线和事实。开头不吸引人或全稿平铺时可以重组叙事，不能仅加感叹号、换
几个形容词就算完成修改。保持主题、已核验事实和来源；不添加虚构数据、来源
URL 或素材 ID。尽量保留未改变段落的 segment_id；新增段落使用唯一 ID，不
宣称新稿可以沿用旧稿的通过结论。

## 唯一输出

仅返回符合 ScriptRewrite schema 的完整 JSON，不返回局部补丁或 Markdown：

- `script`：修改后的完整 Script（所有段落，不是只含改动段）。
- `response`：简短中文，逐条说明本轮 critique 问题在哪些段落如何解决；
  无法采纳的意见说明证据或缺口，不虚构补到新素材，也不声称文案已获人工
  认可。response 不进入 narration。
